# P2P-user-tg — поиск свободных юзернеймов Telegram

Парсер перебирает юзернеймы и проверяет, какие из них **не заняты и их можно забрать**:

- **крипта**: монеты, биржи, кошельки, DeFi-термины, сленг, P2P/обмен (`data/crypto.txt`);
- **компании и бренды**: технологии, банки и платежи, авто, мода, еда, игры, телеком (`data/companies.txt`);
- **реальные слова**: ~39 тыс. частых английских слов и ~24 тыс. русских в транслите (`data/words_en.txt`, `data/words_ru.txt`), от частых к редким;
- **короткие 4-символьные**: любые наборы букв, «красивые» (`aaaa`, `abab`, `abba`…), читаемые (`CVCV` — `baba`, `lomo`…) и свои шаблоны.

## Правила юзернеймов Telegram

| | |
|---|---|
| Символы | `a-z`, `0-9`, `_` |
| Первый символ | только буква — не цифра и не `_` |
| Конец | не может заканчиваться на `_`, нельзя `__` подряд |
| 5–32 символа | можно занять **бесплатно** в настройках Telegram |
| 4 символа | **нельзя занять бесплатно** — только купить на [Fragment](https://fragment.com) за TON (аукцион или продажа) |

> На 4-символьные приложение **всегда** пишет «Некорректное имя» — их можно только купить на Fragment. Парсер помечает такие находки как «ТОЛЬКО КУПИТЬ НА FRAGMENT» и даёт ссылку.

Поэтому для 4-символьных парсер ищет те, что **можно получить на Fragment** (статусы `available` — можно начать аукцион, `on auction`, `for sale`), а для 5+ символов — **бесплатно свободные**.

## Самый простой запуск (Windows)

1. Установите Python 3.10+ с https://www.python.org/downloads/ — в установщике **отметьте «Add python.exe to PATH»**.
2. Скачайте этот репозиторий архивом (**Code → Download ZIP**) и распакуйте.
3. Дважды щёлкните **`start.bat`**. В первый раз он сам установит всё нужное в папку парсера (временные файлы тоже кладёт туда, а не на диск C:) — 1–2 минуты.
4. Откроется меню. Если Telegram API ещё не настроен, оно предложит настроить его: просто впишите свои `api_id` и `api_hash` (где их взять — оно подскажет), номер телефона и код из Telegram. Всё сохранится само, вводить второй раз не нужно.

```
=== Поиск свободных юзернеймов Telegram ===

Telegram API: настроен, аккаунт @your_account

  1. Крипта и компании — бесплатные, от 5 символов
  2. Все реальные слова — бесплатные, от 5 символов (долго, ~6 ч)
  3. 4-буквенные слова (doge, defi…) — только КУПИТЬ на Fragment
  4. Красивые 4-символьные (aaaa, abab…) — только КУПИТЬ на Fragment (~1 ч)
  5. Все 4-символьные — только КУПИТЬ на Fragment (долго, ~3 суток)
  6. Проверить свои юзернеймы
  7. Перепроверить найденные через Telegram API (убрать «Некорректное имя»)
  8. Настроить Telegram API (api_id и api_hash)
  9. Открыть папку с результатами
  0. Выход
```

Дальше — только выбирать номер пункта. На других системах то же меню открывается командой `python -m tgparser` без аргументов.

## Установка вручную

Нужен Python 3.10+.

```bash
git clone <этот репозиторий> && cd P2P-user-tg-
pip install -r requirements.txt
```

На Windows вместо `python` и `pip` пишите `py` и `py -m pip`: `py -m pip install -r requirements.txt`, `py -m tgparser words`.

## Быстрый старт

```bash
# Все списки слов: крипта → компании → английские → русские (5–12 символов)
python -m tgparser words

# Только крипта и компании
python -m tgparser words --lists crypto,companies

# Реальные 4-буквенные слова из списков (проверка через Fragment)
python -m tgparser words --min-len 4 --max-len 4

# 4-символьные: красивые → читаемые → все буквенные (по умолчанию)
python -m tgparser short

# Только «красивые» (aaaa, abab, aabb, abba…), ~4.6 тыс. штук
python -m tgparser short --preset pretty

# Свои шаблоны: x + 3 цифры, буква + 3 буквы/цифры
python -m tgparser short --pattern xDDD --pattern LAAA --shuffle --limit 5000

# Свой список (файл — по одному в строке; можно @name, t.me/name)
python -m tgparser check my_names.txt cryptoking durovpay

# Посмотреть, что будет проверяться, без запросов
python -m tgparser words --lists crypto --dry-run
```

Найденное сразу печатается в консоль:

```
[СВОБОДЕН — можно занять] @kriptoobmen  (crypto)  api: свободен
[НЕ ПРОВЕРЕН] @someword  (en)  t.me: профиля нет        ← без Telegram API (нужен VPN)
[ТОЛЬКО КУПИТЬ НА FRAGMENT] @qzxw  (short:LLLL)  fragment: available, 10 TON  https://fragment.com/username/qzxw
```

Прогон можно остановить в любой момент (Ctrl+C) — при следующем запуске той же команды он продолжится с места остановки.

## Как проверяется

Для каждого юзернейма по очереди, от дешёвой проверки к точной:

1. **t.me/юзернейм** — если есть профиль, канал, группа или бот → `taken`. Так отсеивается большинство.
2. **fragment.com/username/юзернейм** — продаётся / на аукционе / куплен как NFT.
3. **Telegram API** (`account.checkUsername`, если в `.env` есть ключи) — точный ответ, можно ли занять имя прямо сейчас.

### Зарезервированные имена («Некорректное имя»)

Многие имена — особенно бренды (`bayern`, …) — Telegram зарезервировал: профиля на t.me нет, на Fragment не продаются, но занять их нельзя — приложение пишет **«Некорректное имя»**. Снаружи (t.me, Fragment) они выглядят как свободные, отличить их может только Telegram API.

- **С ключами API** в `.env` такие имена получают статус `invalid` и **не попадают** в списки находок.
- **Без API** они попадут в `likely_free.txt`. Отсеять их потом можно одной командой — она перепроверит только найденные «вероятно свободные»:

```bash
python -m tgparser confirm
```

### Статусы

| Статус | Значение |
|---|---|
| `free` | Telegram API подтвердил: можно занять бесплатно |
| `likely_free` | профиля нет и на Fragment не продаётся; подтвердить через `--api` |
| `fragment` | можно получить на Fragment (аукцион, ставка, покупка); цена в TON — если она указана на странице |
| `taken` | занят: есть профиль/канал/бот или куплен на Fragment |
| `unavailable` | 4 символа, но на Fragment сейчас недоступен |
| `invalid` | зарезервирован Telegram — в приложении «Некорректное имя» (бренды, запрещённые слова) или не проходит правила |
| `error` | проверить не удалось — проверится снова при следующем запуске |

## Точная проверка через Telegram API

Проще всего — пункт **«Настроить Telegram API»** в меню (или `python -m tgparser setup`): он спросит `api_id` и `api_hash`, сохранит их в `.env` и сразу выполнит вход (номер телефона, код, облачный пароль, если есть). Вручную:

1. Зайдите на https://my.telegram.org → **API development tools**, создайте приложение, возьмите `api_id` и `api_hash`.
2. Скопируйте `.env.example` в `.env` и впишите их.
3. Запускайте как обычно — **с ключами в `.env` API включается сам**. При первом запуске Telegram спросит номер телефона, код и облачный пароль (если есть) — сессия сохранится в `tgparser.session`.

```bash
python -m tgparser words --lists crypto,companies   # API используется автоматически
python -m tgparser confirm                           # перепроверить уже найденные likely_free
python -m tgparser words --no-api                    # без API, только t.me и Fragment
```

API вызывается только для тех, кто прошёл t.me и Fragment, поэтому лимит тратится экономно. Если Telegram даёт FloodWait дольше `--max-flood-wait` (по умолчанию 900 с), проверка через API отключается, а прогон продолжается без неё; `confirm` в этом случае останавливается и продолжит при следующем запуске.

Удобная схема: сначала быстро прогнать списки без аккаунта (`--no-api`), потом подтвердить короткий список находок через `confirm`.

### «Attempt 1 at connecting failed: TimeoutError» — нет подключения к Telegram

Парсер подключается к серверам Telegram напрямую. Если провайдер этому мешает, вход зависает с `TimeoutError` — при этом приложение Telegram может работать (оно обходит блокировки само). Варианты:

- **VPN** на весь компьютер (не расширение браузера) — включите и снова выберите в меню «Настроить Telegram API»;
- **SOCKS5/HTTP-прокси** — меню само предложит вставить его после неудачного подключения; вручную — строка в `.env`:
  ```
  TG_PROXY=socks5://логин:пароль@адрес:порт
  ```
  (MTProto-прокси вида `tg://proxy?...` не подходят — нужен именно SOCKS5 или HTTP.)

Если Telegram недоступен во время поиска, поиск не останавливается — просто идёт без API (находки будут `likely_free`, их можно потом проверить через `confirm`).

> Используйте **запасной аккаунт**. Файл `*.session` — это доступ к аккаунту: никому его не передавайте (он уже в `.gitignore`).

## Результаты

Всё сохраняется в папку `results/` (меняется через `--out`):

- `results.csv` — все проверенные: `username, length, status, source, detail, checked_at` (открывается в Excel);
- `free.txt`, `likely_free.txt`, `fragment.txt` — находки, сначала самые короткие.

## Шаблоны для коротких юзернеймов

| Символ | Что подставляется |
|---|---|
| `L` | любая буква a–z |
| `V` | гласная (a e i o u y) |
| `C` | согласная |
| `D` | цифра 0–9 |
| `A` | буква или цифра |
| `a`–`z`, `0`–`9`, `_` | ровно этот символ |

Пресеты (`--preset`, можно через запятую):

| Пресет | Шаблоны | Кол-во |
|---|---|---|
| `pretty` | aaaa, abab, aabb, abba, aaab, abbb, aaba, abaa | ~4.6 тыс. |
| `pronounceable` | CVCV, VCVC, CVVC, CVCC, CCVC | ~139 тыс. |
| `letters` | LLLL | 456 976 |
| `alnum` | LAAA (первая — буква) | ~1.2 млн |

Шаблоны не обязательно 4-символьные: `--pattern CVCVC` переберёт 5-буквенные читаемые.

## Свои списки слов

Любой `.txt` с одним словом на строку (строки с `#` — комментарии):

```bash
python -m tgparser words --lists crypto,./my_brands.txt
```

Регистр, пробелы, дефисы и точки убираются сами: `Coca-Cola` → `cocacola`, `crypto.com` → `cryptocom`.
Словари `words_en.txt` / `words_ru.txt` пересобираются скриптом `scripts/build_wordlists.py` (нужен `pip install wordfreq`).

## Скорость и ограничения

- По умолчанию ~3 запроса/с к t.me (`--tme-delay 0.35`) и ~1.6/с к Fragment (`--fragment-delay 0.6`). При ответе 429 задержка увеличивается автоматически.
- После 30 ошибок подряд прогон останавливается (нет интернета или сайт ограничил доступ) — увеличьте задержку или используйте `--proxy`.
- Прокси: `--proxy http://user:pass@host:port` или `--proxy socks5://host:port`.
- Ориентир при настройках по умолчанию: все слова (`words`, ~63 тыс.) — около 6 часов; `pretty` — около часа; все 4-буквенные (`letters`) — около 3 суток (для каждого свободного на t.me нужен ещё запрос к Fragment). Удобно запускать частями через `--limit` или `--shuffle`.
- Почти все популярные слова и бренды уже заняты — свободные чаще находятся среди длинных, редких слов и русского транслита.
